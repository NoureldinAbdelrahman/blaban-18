# Pre-Wednesday Reading Assignments

Goal: arrive at the Wednesday meeting with enough shared evidence to choose an
idea. Nobody needs to read all 21 previous publications before the meeting.

## How to use this file

1. Replace `Reader 1` … `Reader 6` with team names.
2. If the team has four or five members, use the first four or five rows.
3. Each reader covers **three previous publications** plus **the five-paper shortlist
   summary**, not the full text of every shortlist paper.
4. Record each completed reading in
   [`literature_review_log.md`](literature_review_log.md).

## Definition of done for each paper

For every assigned paper, the reader must be able to answer:

1. What cooperative problem is solved, and by which agents?
2. What optimization method is used, and what decision it produces?
3. What was the main result or limitation?
4. Does it support a proposal idea? If yes, which one?
